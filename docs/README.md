# Dokumentasi LingkarPay

| Dokumen | Isi | Jalur |
|---|---|---|
| `DESIGN.md` | Rancangan antarmuka v1: alur, status pesanan, skema, endpoint, outbox, payout. Kontrak antar jalur | Payment gateway |
| `API.md` | Endpoint backend, body, respons, kode error | Payment gateway |
| `ERD.md` | Diagram basis data (Mermaid) dan aturan integritas | Payment gateway |
| `openapi.yaml` | Spesifikasi OpenAPI 3 semua endpoint. Impor ke Postman atau buka di editor.swagger.io | Payment gateway |
| `PENJELASAN_KODE.md` | Panduan menjelaskan kode per komponen, alur, tanya-jawab, dan batasan | Payment gateway |
| `BUKTI_SEPOLIA.md` | Bukti end to end di Ethereum Sepolia: alamat contract, hash transaksi, state dari contract, cara mengulang | Payment gateway dan smart contract |
| `DEMO.md` | Runbook demo dan progress report sisi payment gateway, plus jawaban pertanyaan umum | Payment gateway |
| `IRIS.md` | Panduan mencoba payout Midtrans Iris sandbox (opsional) | Payment gateway |
| `RULES.md` | Aturan kerja: git, keamanan, pembayaran, kode | Semua |
| `PLAN.md` | Rencana pengerjaan, status, hasil uji | Payment gateway |
| `DEV_LOG.md` | Log pengembangan ide dan keputusan | Semua (tambahkan entri) |
| `AI_STATEMENT.md` | Pernyataan penggunaan alat AI dan cara verifikasi | Semua |
| `business-case/` | Business case, revisi proposal, slide, video demo | Business case |

Dokumen yang diminta rubrik Dokumentasi: log ide (`DEV_LOG.md`), user stories (oleh jalur frontend), ERD (`ERD.md`), arsitektur (`DESIGN.md`, `docs` proposal), API (`API.md`), riwayat Git per anggota (repositori ini), pernyataan AI (`AI_STATEMENT.md`).
